## 一、研究简介

零售门店的库存决策直接影响现金流、货架可得性与顾客体验。本文以沃尔玛
（Walmart）45 家门店 2010–2012 年的周度销售与运营数据为对象，构建了
**“结构化数据 + NLP 文本测度”双驱动的库存可视化与预测框架**：

1. 重建门店-部门-周层面的销售与运营面板数据；
2. 基于中英文双语情感词典构建 **零售供应链情绪指数（RSCI）** 这一 NLP 测度；
3. 用 (s, S) 补货策略仿真生成库存水平与缺货风险标签；
4. 训练 **随机森林回归模型**（预测库存水平）与 **随机森林分类模型**（预警缺货风险）；
5. 输出可视化图表与企业-年份测度面板表。

## 二、方法要点

**1）NLP 测度：零售供应链情绪指数 RSCI**

对每条文本按双语情感词典统计正/负向词频，单条文本情感得分为

```
RSCI_i = (Pos_i − Neg_i) / (Pos_i + Neg_i)
```

再按月度取均值并裁剪至 `[-1, 1]`，正值表示乐观的零售供应链情绪。

**2）库存动态仿真**

```
Inv_t = max{Inv_{t−1} + Order_t − Sales_t, 0}
```

采用 (s, S) 策略变体：目标库存 `Target = 2.5 × EWMA4 + 0.8 × Std4`，
再订货点 `Reorder = 0.6 × EWMA4`；当 `Sales_t > Inv_{t−1} + Order_t` 时记为缺货。

**3）随机森林模型**

- 回归：200 棵树，最大深度 20，预测 `Inventory_Level`；
- 分类：200 棵树，最大深度 15，`balanced` 类别权重，预测 `Stockout`；
- 按时间顺序划分训练集（2010-02 ~ 2012-05）与测试集（2012-06 ~ 2012-11），避免数据泄露。

## 四、数据说明（重要）

核心数据的字段结构、取值分布与统计特征，均参照 Kaggle 官方竞赛
**“Walmart Recruiting - Store Sales Forecasting”**（数据由 Walmart 官方提供，
覆盖 2010-02-05 至 2012-11-01 的 45 家门店周度销售与运营信息）重建。

由于研究环境无法直连 Kaggle 下载原始 CSV，仓库中的 `data/raw/` 数据为
**依据公开数据结构与汇总统计量重建的高保真演示数据**，保留 45 家门店、
门店类型（A/B/C）与周度频率，并选取 30 个代表性部门建模。它用于教学演示与方法复现，
**不能用于真实商业结论推断**。

> **替换为真实数据**：把从 Kaggle 下载的 `train.csv` / `features.csv` / `stores.csv`
> 直接覆盖放入 `data/raw/`，重新运行 `python src/pipeline.py` 即可，
> 代码会自动识别真实数据并跳过重建步骤。

各文件的来源与处理步骤详见 `output/数据来源说明.txt`。

## 七、局限性

- 数据为重建的演示数据，非 Kaggle 原始文件；
- RSCI 采用词典法构建，可用 BERT / SnowNLP 等预训练模型进一步改进；
- 库存仿真的补货参数为假设值，实际应用应结合企业 ERP 真实订货数据校准。
